# Telegram-бот для личных диалогов

Пользователь выбирает категорию, и бот открывает тему в его личке. Все подключённые админы получают кнопку «Принять чат». После принятия во всех карточках появляется имя админа. Кнопка перехода в рабочую тему появляется у принявшего, а пользователь получает уведомление. В конце пользователь может поставить оценку от 1 до 5 и начать новый чат.

## Запуск

1. Создай бота через [@BotFather](https://t.me/BotFather) и включи темы в личных чатах в настройках бота. Там же можно отключить ручное создание и удаление тем пользователями. [Документация Telegram](https://core.telegram.org/bots/features#topics-in-private-chats)
2. С Go 1.24 или новее выполни в PowerShell `Copy-Item .env.example .env` и запиши токен в `BOT_TOKEN`.
3. Укажи свой Telegram ID в `OWNER_ID`. Если ID неизвестен, отправь `/start` новому боту со своего аккаунта и выполни `go run . -owner-id` до запуска бота. Команда покажет ID отправителя последнего `/start`.
4. Запусти `go run .`. Отправь боту `/start`, открой `/admins` и создай одноразовую ссылку для админа. После перехода по ссылке подтверди аккаунт кандидата в сообщении от бота или через `/admins`.

Для проверки зайди со второго аккаунта, выбери категорию и отправь фото или сообщение до принятия чата. Затем прими обращение со своего аккаунта, ответь из темы и нажми «Завершить чат». На втором аккаунте появится оценка.

## Оформление

- По умолчанию бот отправляет первый стикер из [Bocchimemes2](https://t.me/addstickers/Bocchimemes2_by_fStikBot). `WELCOME_STICKER_NUMBER` задаёт номер в наборе, а пустой `WELCOME_STICKER_SET` отключает приветственный стикер.
- `CATEGORIES_JSON` задаёт список категорий. `EMOJI_JSON` задаёт кастомные эмодзи на кнопках по ID категорий и ключам `new`, `take`, `close`, `invite`, `star` и `open`. Для стандартного бота кастомные эмодзи требуют Telegram Premium у владельца бота в BotFather. [Требования Telegram](https://core.telegram.org/bots/api#inlinekeyboardbutton)

Бот копирует текст, фото, альбомы, файлы, голосовые, стикеры и другие поддерживаемые Telegram сообщения. Bot API ограничивает копирование служебных сообщений, счетов, платного контента и некоторых опросов. [Ограничения Bot API](https://core.telegram.org/bots/api#copymessage)

После завершения история остаётся в личных темах, а пересылка останавливается. Состояние хранится в `data/state.json`. Запускай один экземпляр бота с этим токеном.

## UTBPanel

1. Собери архив `./scripts/release.ps1 -Version v0.1.0` в PowerShell. В `dist` появятся архив со статическим бинарником Linux amd64 и контрольная сумма SHA-256.
2. В панели добавь бота с токеном из BotFather и задай `OWNER_ID` в переменных окружения бота. Загрузи архив во вкладке «Деплой» или подключи GitHub Releases с маской `support-bot_*_linux_amd64.tar.gz`. [Документация UTBPanel](https://github.com/SnimanOff/UTBPanel#readme)
3. Примени настройки из `tgpanel.yaml`, выбери версию и запусти её. Панель предоставляет `BOT_TOKEN`, `PORT`, `WEBHOOK_SECRET` и `DATA_DIR`. При запуске в панели бот принимает вебхуки на loopback, проверяет секрет и пишет состояние в `DATA_DIR/state.json`.

## Крестики-нолики

Кнопка появляется в активных темах после настройки `MINI_APP_URL`. Укажи публичный HTTPS-адрес и направь запросы к `/game` и `/game/*` на HTTP-порт бота через обратный прокси. При локальном запуске с опросом Telegram этот порт задаёт `MINI_APP_ADDR`. В панели используй её локальный порт бота. Публичный маршрут вебхука остаётся отдельным от маршрутов игры.

Бот проверяет подпись Telegram Mini App и допускает к партии только пользователя и назначенного админа. Состояние и очередь ходов хранятся на сервере. [Документация Telegram](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app)

## Проверки

Выполни `go test ./...` и `go vet ./...`. В Telegram проверь карточки двух админов, закрытие, оценку и игру с двух аккаунтов после подключения HTTPS.
